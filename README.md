# Director IA — Sitio web

Landing page de Director IA. HTML/CSS/JS estático, sin dependencias ni proceso de build.

## Estructura

- `index.html` — página completa
- `assets/og-image.png` — imagen de vista previa para redes sociales
- `assets/og-image.html` — fuente editable de la imagen anterior

## Desarrollo local

Abrir `index.html` directamente en el navegador, o servirlo con cualquier servidor estático.

## Despliegue

Conectado a Vercel — cada push a `main` despliega automáticamente a producción.
